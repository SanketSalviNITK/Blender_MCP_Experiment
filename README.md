# Blender MCP Experiment

> Learn 3D automation, prompt engineering, and agentic AI workflows by building real things in Blender using Claude Code and MCP.

---

## What Is This?

This is a structured, hands-on course for learning how to control Blender entirely through natural language using **Claude Code** and the **Model Context Protocol (MCP)**.

No Python required. No manual Blender clicking. Just prompts.

## Setup

1. Install [Blender 4.x](https://www.blender.org/download/)
2. Enable the Blender MCP add-on in Blender preferences
3. Open Claude Code in this repo
4. Verify connection: *"List all objects in the Blender scene"*
5. Start with [Module 1](docs/module-1/overview.md)
