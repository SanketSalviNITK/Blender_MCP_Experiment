# Module 8 — Capstone Project

## Goal
Apply everything from the course to build a complete, polished Blender project from scratch — planned, built, rendered, documented, and shipped to GitHub entirely using Claude Code and prompts.

## Lessons
| Lesson | Title | Duration |
|--------|-------|----------|
| [8.1](lesson-8.1.md) | Pick a project and define scope | ~30 min |
| [8.2](lesson-8.2.md) | Plan it with Claude using agentic mode | ~30 min |
| [8.3](lesson-8.3.md) | Build it lesson by lesson | ~2–3 hours |
| [8.4](lesson-8.4.md) | Commit, document, and push to GitHub | ~30 min |
| [8.5](lesson-8.5.md) | Reflect — what worked, what didn't | ~20 min |

## Suggested Capstone Projects

Choose one (or propose your own):

| Project | Complexity | Skills Used |
|---------|-----------|-------------|
| **Procedural City** | High | Scripting, loops, randomization, rendering |
| **Product Visualizer** | Medium | Materials, lighting, camera automation |
| **Solar System** | Medium | Transforms, animation, materials |
| **Abstract Art Generator** | Low-Medium | Scripting, randomization, creativity |
| **Architectural Walkthrough** | High | Modeling, camera paths, rendering pipeline |

## Deliverables

By the end of the capstone:
- [ ] A complete Blender scene (.blend file) in `/experiments/capstone/`
- [ ] Rendered output images in `/experiments/capstone/renders/`
- [ ] All reusable scripts saved to `/scripts/`
- [ ] A writeup in `/experiments/capstone/README.md`
- [ ] Everything committed and pushed to GitHub

## What You Will Have Learned

Completing this capstone proves you can:
- Direct Claude through a complex, multi-session project
- Use agentic workflows effectively
- Apply prompt engineering patterns in real creative work
- Build, version, and document a 3D project professionally
