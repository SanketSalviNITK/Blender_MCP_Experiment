# Blender MCP Mastery — Course Overview

> **Learn 3D automation, prompt engineering, and agentic AI workflows by building real things in Blender using Claude Code and MCP.**

---

## What You Will Learn

By the end of this course you will be able to:

- Connect Claude Code to Blender via MCP and control the entire 3D environment using natural language
- Write effective prompts for complex, multi-step creative and technical tasks
- Use agentic workflows — letting Claude plan and execute tasks autonomously
- Leverage MCP connectors (filesystem, computer-use, browser) to build real pipelines
- Generate, save, and version reusable Blender Python scripts
- Automate rendering pipelines from prompt to final image
- Use advanced Claude Code features: memory, hooks, subagents, and scheduled tasks
- Document and ship a complete end-to-end Blender project on GitHub

---

## Prerequisites

| Requirement | Notes |
|-------------|-------|
| Blender 4.x installed | [Download](https://www.blender.org/download/) |
| Claude Code (CLI) installed | Running in this repo |
| Blender MCP add-on enabled | Connected and active |
| Basic familiarity with Blender UI | Knowing what the viewport is is enough |
| No Python required | Claude writes the code — you learn to direct it |

## How Each Lesson Works

Every lesson follows the same rhythm:

1. **Concept** — A clear explanation of the idea or tool
2. **Live Demo** — We do it together in Blender via Claude Code
3. **Your Turn** — You write the prompt; feedback is given
4. **Commit & Document** — Every experiment is saved to this repo
