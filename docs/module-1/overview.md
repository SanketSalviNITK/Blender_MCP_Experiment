# Module 1 — Foundations

## Goal
Understand the full stack: how Claude Code, MCP, and Blender connect, and how to start giving it instructions confidently.

## Why This Module Matters
Before you can automate anything, you need a mental model of how the pieces fit together. Most people skip this and then write vague prompts that produce vague results. This module fixes that.

## What You Will Build
A simple Blender scene with a few objects — created entirely through prompts. No clicking in Blender required.

## Key Concepts Introduced
- MCP (Model Context Protocol)
- Claude Code tools: Read, Write, Bash, Blender MCP tools
- The Blender Python API (`bpy`)
- Prompt specificity

## Prerequisites
- Blender open and running
- Blender MCP add-on enabled and connected
- Claude Code session active in this repo
