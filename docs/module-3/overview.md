# Module 3 — Agentic Workflows

## Goal
Learn to hand off complex, multi-step Blender tasks to Claude as an autonomous agent — letting it plan, decide, and execute without you micromanaging every step.

## Lessons
| Lesson | Title | Duration |
|--------|-------|----------|
| [3.1](lesson-3.1.md) | What is an agent? How Claude breaks down tasks | ~20 min |
| [3.2](lesson-3.2.md) | Multi-step scene building (agent does it all) | ~40 min |
| [3.3](lesson-3.3.md) | Using TaskCreate to track work inside sessions | ~20 min |
| [3.4](lesson-3.4.md) | When to guide vs. when to let the agent run | ~20 min |
| [3.5](lesson-3.5.md) | **PE:** Writing agentic briefs | ~30 min |

## What You Will Build
A full interior room scene — designed and built autonomously by Claude with minimal guidance from you.

## Key Concepts Introduced
- Agentic vs. conversational mode
- Task decomposition
- TaskCreate and progress tracking
- Autonomous decision-making in 3D space
- The agentic brief prompt pattern
