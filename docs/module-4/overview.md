# Module 4 — Connectors & Plugins

## Goal
Connect Blender workflows to the real world using MCP connectors — the filesystem, the browser, and computer-use — and chain them together into production pipelines.

## Lessons
| Lesson | Title | Duration |
|--------|-------|----------|
| [4.1](lesson-4.1.md) | What are MCP connectors? (filesystem, browser, computer-use) | ~20 min |
| [4.2](lesson-4.2.md) | Using the filesystem connector — save/load .blend files | ~30 min |
| [4.3](lesson-4.3.md) | Using computer-use — take screenshots, verify renders | ~25 min |
| [4.4](lesson-4.4.md) | Chaining connectors: generate → render → save → preview | ~40 min |
| [4.5](lesson-4.5.md) | **PE:** Tool-aware prompting | ~30 min |

## What You Will Build
An end-to-end pipeline: Claude generates a scene, renders it, saves the output, and opens it in the browser for review — all from a single prompt.

## Key Concepts Introduced
- MCP connector ecosystem
- File I/O for .blend and render files
- Computer-use for visual verification
- Pipeline composition
- Tool-aware prompting (telling Claude which tools to use)
