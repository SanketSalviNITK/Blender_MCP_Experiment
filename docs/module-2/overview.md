# Module 2 — Scene Basics

## Goal
Control every fundamental element of a Blender scene — objects, materials, lights, and cameras — using only natural language prompts.

## Lessons
| Lesson | Title | Duration |
|--------|-------|----------|
| [2.1](lesson-2.1.md) | Adding, moving, scaling, rotating objects | ~30 min |
| [2.2](lesson-2.2.md) | Materials and colors | ~30 min |
| [2.3](lesson-2.3.md) | Lights and cameras | ~25 min |
| [2.4](lesson-2.4.md) | Organizing a scene (collections, naming) | ~20 min |
| [2.5](lesson-2.5.md) | **PE:** Chain-of-thought prompts | ~30 min |

## What You Will Build
A fully lit, camera-ready product visualization scene — entirely through prompts.

## Key Concepts Introduced
- Object transforms (location, rotation, scale)
- Principled BSDF materials
- HDRI and area lighting
- Camera placement and field of view
- Collections and naming conventions
- Chain-of-thought prompt pattern
