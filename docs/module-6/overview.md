# Module 6 — Rendering Pipeline

## Goal
Automate the full rendering pipeline: set up render settings, render to file, batch multiple scenes, and use prompts to adjust and improve the final output.

## Lessons
| Lesson | Title | Duration |
|--------|-------|----------|
| [6.1](lesson-6.1.md) | Setting render settings via Claude | ~25 min |
| [6.2](lesson-6.2.md) | Rendering to file and previewing output | ~30 min |
| [6.3](lesson-6.3.md) | Batch rendering multiple scenes | ~35 min |
| [6.4](lesson-6.4.md) | Post-processing prompts (lighting, camera adjustments) | ~30 min |
| [6.5](lesson-6.5.md) | **PE:** Feedback loops and correction prompts | ~30 min |

## What You Will Build
A fully automated render pipeline that produces a set of product shots from multiple camera angles — no manual Blender interaction needed.

## Key Concepts Introduced
- Cycles vs. EEVEE render engines via prompts
- Resolution, samples, output path settings
- Camera angle automation
- Batch rendering with Python loops
- Feedback loop prompting pattern
