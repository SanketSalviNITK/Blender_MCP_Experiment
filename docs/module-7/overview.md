# Module 7 — Advanced Agentic Patterns

## Goal
Master the most powerful Claude Code features: subagents for parallel work, persistent memory, hooks for automated behaviors, and scheduled tasks for recurring pipelines.

## Lessons
| Lesson | Title | Duration |
|--------|-------|----------|
| [7.1](lesson-7.1.md) | Subagents — spawning parallel tasks | ~30 min |
| [7.2](lesson-7.2.md) | Memory system — teaching Claude your preferences | ~25 min |
| [7.3](lesson-7.3.md) | Hooks — auto-actions before/after Claude does something | ~30 min |
| [7.4](lesson-7.4.md) | Scheduled tasks — recurring pipelines | ~25 min |
| [7.5](lesson-7.5.md) | **PE:** System-level prompting & CLAUDE.md | ~30 min |

## What You Will Build
A smart Blender assistant that remembers your style preferences, auto-saves scenes on a schedule, and can run parallel scene generation tasks simultaneously.

## Key Concepts Introduced
- Subagent spawning for parallel execution
- The Claude Code memory system (user, project, feedback memories)
- Hooks in settings.json (pre/post tool actions)
- Scheduled cron-style tasks
- CLAUDE.md as a persistent system prompt
