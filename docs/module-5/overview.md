# Module 5 — Scripting & Automation

## Goal
Go beyond one-off prompts: generate reusable, parametric Blender Python scripts that can create entire scenes, loops, and randomized variations — all authored by Claude, saved to your repo.

## Lessons
| Lesson | Title | Duration |
|--------|-------|----------|
| [5.1](lesson-5.1.md) | Claude writes bpy scripts — understanding the output | ~25 min |
| [5.2](lesson-5.2.md) | Parametric scene generation (city blocks, grids) | ~40 min |
| [5.3](lesson-5.3.md) | Looping and randomization in generated scripts | ~35 min |
| [5.4](lesson-5.4.md) | Saving scripts and versioning with Git | ~20 min |
| [5.5](lesson-5.5.md) | **PE:** Iterative refinement loops | ~30 min |

## What You Will Build
A parametric city block generator — a script that creates a randomized grid of buildings with varying heights, materials, and spacing, controlled by parameters you define.

## Key Concepts Introduced
- Reading and understanding bpy scripts
- Parametric design with variables
- Python loops and randomization in Blender context
- Script versioning and reuse
- The iterative refinement prompt pattern
